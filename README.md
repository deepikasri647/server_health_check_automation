# Server Health Check & Monitoring Automation

## 📌 Overview
This project is designed to monitor and report the health status of cloud infrastructure services.  
It collects and verifies system-level and service-level metrics to ensure infrastructure stability and availability.

The report helps in identifying performance issues, service failures, and resource utilization status.

---

## 🚀 Infrastructure Covered

- OVH Cloud Servers
- AWS RDS
- AWS EKS
- GitHub Repositories

---

## 🔍 Health Check Parameters

### 🖥 Server Monitoring
- CPU Usage
- Memory Usage
- Disk Storage
- Network Status
- Uptime Status

### ☸ EKS Monitoring
- Pod Status
- Running/Failed Pods
- Cluster Health Verification

### 🔁 Application Monitoring
- PM2 Application Status
- Nginx Service Status

### 💾 Backup Verification
- Backup completion status check
- Verification of scheduled backup execution

### 📂 GitHub Repository Tracking
- Repository Name
- Last Updated Date
- Public / Private Status

---

## ⚙️ Purpose

- Ensure daily infrastructure monitoring
- Detect performance issues early
- Verify service availability
- Maintain system stability
- Support proactive issue resolution
